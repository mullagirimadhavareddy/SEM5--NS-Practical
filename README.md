# Cryptography and Network Security (CNS) Practicals - Semester 5

This repository contains practical implementations and HTML documentation for **Cryptography and Network Security (2CEIT5PE11)**.

## 📁 Repository Structure
- `SEM5NSPractical.html` - Full code examples, explanations, and output logs.
- `images/` - Output screenshots for each practical.

## 🛠️ Practicals Covered
- **Practical 1:** Caesar Cipher (Standard, Modified, File Handling)
- **Practical 2:** Brute-force Cryptanalysis on Caesar Cipher
- **Practical 3:** Polyalphabetic Cipher (Vigenère)
- **Practical 4:** Playfair Cipher
- **Practical 5:** Rail-Fence Cipher
- **Practical 6:** Hill Cipher ($3 \times 3$ matrix)
- **Practical 7:** Columnar Transposition Cipher
